# Security Policy

## Supported Versions

Currently, only the latest `main` branch and tagged releases are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within AgentGuard, please do **NOT** open a public issue. 

Instead, we practice responsible disclosure. Please report the vulnerability through the GitHub Private Vulnerability Reporting mechanism available in this repository's "Security" tab.

If Private Vulnerability Reporting is unavailable, please reach out to the maintainers directly through available private channels before publishing any details.

**When reporting, please include:**
- A detailed description of the vulnerability and its impact.
- Steps to reproduce the issue (including any necessary configuration).
- Potential scenarios where this vulnerability could be exploited.
- Any suggested mitigations or fixes.

## Responsible Disclosure Guidance

We ask that you:
- Do not publish or share exploit details publicly before coordinating with the maintainers and allowing reasonable time for a patch.
- Do not exploit the vulnerability in a way that risks the data or operations of other users.

We will acknowledge your report as quickly as possible and keep you updated on the progress of the remediation.
